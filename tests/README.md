# Тесты

Тесты организуются по уровням:

- `unit/` — проверка отдельных функций, хуков и компонентов.
- `integration/` — проверка взаимодействия модулей и сервисов.

Тестовый фреймворк и npm-скрипты будут добавлены при настройке инфраструктуры тестирования. Не отмечайте проверки как пройденные, если они не запускались.
