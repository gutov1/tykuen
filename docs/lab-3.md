# ЛР 3. Структура проекта в СКВ и стандарты команды

## Что сделано

- Инициализирован Git-репозиторий, модель ветвления `main` / `develop` / `feature/*`.
- Создан каркас приложения: React + TypeScript + Vite, тестовый фреймворк Vitest.
- Структура каталогов: `src/`, `tests/`, `docs/`, `supabase/migrations/`, `public/`, `.github/`.
- Утверждены стандарты: именование веток, Conventional Commits, стиль кода (ESLint, Prettier, EditorConfig), правила комментариев, процедура code review — [CONTRIBUTING.md](../CONTRIBUTING.md).
- Добавлен шаблон Pull Request — [.github/pull_request_template.md](../.github/pull_request_template.md).
- Заведён журнал решений — [DECISIONS.md](DECISIONS.md).

| Входит в MVP                                     | После защиты                        |
| ------------------------------------------------ | ----------------------------------- |
| Регистрация, вход, восстановление пароля         | Смена email                         |

| Объявления: товары и услуги, до 5 фото           | Расширенная оптимизация изображений |
| Способ сделки: продам / обменяю / бесплатно      | Чат из профиля пользователя         |
| Лента свежих объявлений, поиск, фильтры          |                                     |
| Избранное                                        |                                     |
| Текстовый чат в реальном времени                 |                                     |
| Отметка «Продано»                                |                                     |
| Жалобы на объявления                             |                                     |
| Лимиты: 1 объявление в сутки, 50 активных (в БД) |                                     |
| Установка как PWA                                |                                     |
