# Исходный код

Планируемые каталоги:

- `app/` — запуск, маршрутизация и конфигурация приложения.
- `components/` — общие UI-компоненты.
- `features/` — модули предметной области.
- `pages/` — страницы приложения.
- `hooks/` — повторно используемые React-хуки.
- `lib/` — вспомогательные библиотеки и клиенты.
- `services/` — работа с внешними сервисами.
- `types/` — общие типы.
- `styles/` — глобальные стили.

Создавайте конкретные модули по мере реализации функций.
