# Тыкуэн

Локальная PWA-платформа для жителей Кабардино-Балкарской Республики: продать, отдать бесплатно или обменять вещи, предложить услуги и договориться напрямую.

> Люди помогают людям находить вещи и услуги рядом — без комиссий, доставки и лишней сложности.

Проект выполняется в рамках дисциплины «Основы технологии командной разработки программного обеспечения».

## Стек

TypeScript · React · Vite · Supabase (PostgreSQL, Auth, Storage, Realtime) · PWA · ESLint · Prettier · Vitest

## Запуск

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env.local   # заполнить ключи Supabase
npm run dev
```

| Команда             | Что делает                  |
| ------------------- | --------------------------- |
| `npm run dev`       | Сервер разработки           |
| `npm run build`     | Production-сборка в `dist/` |
| `npm run lint`      | Проверка ESLint             |
| `npm run typecheck` | Проверка типов TypeScript   |
| `npm test`          | Unit-тесты (Vitest)         |
| `npm run format`    | Форматирование Prettier     |

## Структура репозитория

```
src/                  исходный код приложения
tests/                тесты
supabase/migrations/  миграции базы данных
docs/                 документация, решения, отчёты по лабораторным
public/               статические файлы, иконки
.github/              шаблоны PR и issues, CI
PROJECT_CONTEXT.md    требования к продукту
CONTRIBUTING.md       правила командной разработки
```
